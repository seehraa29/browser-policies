## Description

These scripts are intended to apply privacy based policies for Brave, Chrome, Edge and Firefox browsers.

You can tweak these according to your needs. Policies can change when the browser developers amend a policy, remove it or introduce a new policy.

You can run the REG files in a windows environment for Brave, Chrome or Edge, that will add the policy to your browser.
For Firefox, the policy has to be applied with a BAT file in Windows.

For Linux environments, use the shell scripts.

apply_brave_policies.reg
apply_brave_policies.sh

apply_chrome_policies.reg
apply_chrome_policies.sh

apply_edge_policies.reg
apply_edge_policies.sh

apply_firefox_policies.bat
apply_firefox_policies.sh

### Removing Policy

Removing the policy can be done by running the scripts below and passing in "brave", "chrome", "edge" or "firefox" as a parameter.

remove_browser_policies.bat
remove_browser_policies.sh
